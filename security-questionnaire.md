Security Questionnaire Example

Question  
How do you protect sensitive data  

Answer  
Sensitive data is encrypted at rest and in transit using industry standard methods. Access is restricted based on role and monitored for unauthorized activity  

---

Question  
How do you manage user access  

Answer  
Access is granted based on role and business need. Permissions are reviewed regularly and removed when no longer required  

---

Question  
Do you have an incident response process  

Answer  
Yes. Security incidents are identified, contained, and investigated using a defined response process. Actions are documented and reviewed to improve future response  

---

Question  
How do you monitor systems  

Answer  
Systems are monitored for unusual activity. Logs are reviewed and alerts are investigated to detect and respond to potential threats  

---

Question  
How do you protect data in transit  

Answer  
All data in transit is encrypted using secure protocols and restricted to authorized systems
